# 🔍 GitHub公開前チェッカー (Web版)

GitHubへプロジェクトを公開する前に、リポジトリの構成・設定・不要ファイル・セキュリティ上の懸念点を**ローカル環境だけで自動チェックするGUIアプリケーション**です。

![Node](https://img.shields.io/badge/node-%3E%3D18.0.0-green.svg)
![Security](https://img.shields.io/badge/security-100%25%20Local-brightgreen.svg)

---

## 🌟 主な特徴

- 💻 **ローカルWebアプリケーション**: コマンド操作不要！ブラウザ上のGUIから直感的に操作できます。
- 🔒 **完全ローカル・外部通信ゼロ**: コードやファイルが外部サーバーやクラウドへ送信されることは一切ありません。
- 📊 **総合スコアリング (0〜100点)**: 必須/推奨項目・不要ファイル・大容量ファイルからリポジトリ品質をスコア化。
- 📝 **Markdownレポート自動出力**: 診断結果をワンクリックで `CHECK_REPORT.md` としてダウンロード保存可能。
- ⚡ **Zero External Dependency**: 外部フレームワークに依存しない軽量・高速動作。

---

## 🚀 使い方 (Windows)

1. **`ツール起動.bat` をダブルクリック**
   - ローカルサーバーが自動起動し、Webブラウザが開きます。
2. **プロジェクトフォルダを指定**
   - チェックしたいプロジェクトの絶対パス（例: `C:\Projects\my-project`）または相対パスを入力。
3. **大容量ファイル判定閾値を設定 (オプション)**
   - 必要に応じて大容量ファイル判定サイズ（デフォルト: 10 MB）を調整。
4. **「🔍 チェック開始」をクリック**
   - 自動でファイル検査およびスコア算出が行われ、結果が表示されます。
5. **「📝 Markdownレポート保存」**
   - レポート保存ボタンを押して診断レポート (`CHECK_REPORT.md`) を保存します。

## 📋 チェック項目一覧

### 1. 必須ファイル
- `README.md` (プロジェクト概要)
- `LICENSE` (ライセンス表記)
- `.gitignore` (Git除外設定)
- `package.json` (または各言語のプロジェクト設定ファイル)

### 2. 推奨ファイル
- `CHANGELOG.md` (変更履歴)
- `CONTRIBUTING.md` (貢献ガイド)
- `docs/` (ドキュメントディレクトリ)

### 3. 検出・警告ファイル (不要ファイル)
- `.env`, `.env.local` (秘密情報・環境変数)
- `node_modules/` (依存ライブラリ)
- `.DS_Store`, `Thumbs.db` (OS固有のシステムファイル)
- `temp/`, `cache/`, `*.log`, `*.tmp` (一時キャッシュ・ログ)

### 4. 大容量ファイル
- 指定閾値（標準10MB）を超えるファイルを検出。Git LFS や外付け管理を推奨します。

## 🛠️ 開発・ビルドコマンド

```bash
# 依存関係のインストール
npm install

# ローカルWebサーバーの起動 (開発モード)
npm run dev

# 自動テストの実行 (全17件の単体・統合・E2Eテスト)
npm test

# アプリケーションのビルド
npm run build

# ビルド済みサーバーの起動
npm start
```
